# Fate/stay night — script browser

Public Japanese/MAO-English reader for the source-reconciled 712-scene, 25,507-passage manuscript.

The site intentionally contains no patch download, installation instructions, runtime-compatibility claim, mirror moon comparison, or translation-audit layer. Those are later and separately verified publication stages.

Build reader data with `python3 scripts/build-reader-data.py`. Run locally with `npm ci` and `npm run dev -- --host 127.0.0.1`. Production checks are `npm run typecheck` and `npm run build`.
