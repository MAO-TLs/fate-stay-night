# v1.3.0 — script display and edition fixes

This release corrects broken sentence segmentation, displaced paragraph and click boundaries, and missing edition-specific text across the patch. It includes the general layout pass and resolves the ten remaining held display rows against the available Japanese witnesses.

- Keep sentences and voice cues together in the reported dialogue cases.
- Restore Japanese-supported paragraph boundaries and scene order.
- Keep simultaneous greetings in their native two-column display without duplicating them in narration.
- Restore omitted original-edition passages and separate original and all-ages alternatives.

The release changes 664 script entries relative to v1.2.1. All 895 archive entries round-trip; non-script assets and all 27,918 page labels are preserved. The browser manuscript remains at script version v1.2.0.

## Install

Close the game and replace its previous `patch_lang_english.xp3` with this archive. Keep the Ultimate Edition core and optional feature patches. Back up the previous language archive if you want to revert.
