# v1.2.1 — text display fixes

This update corrects text clipping in several specially centered passages and removes an editorial placeholder that the game interpreted as an unknown command.

- Center each of the five explicitly multiline centered passages using each line’s own width.
- Split three overwide centered lines at existing sentence or phrase boundaries.
- Remove the stray placeholder and its otherwise empty line wait.

The update changes seven script entries. Dialogue wording, page labels, page-break commands, fonts, other assets, and the online manuscript remain unchanged from v1.2.0.

Replace the previous `patch_lang_english.xp3` with the new archive while the game is closed. Keep the existing Ultimate Edition core and optional feature patches.

## Reproduce the display repair

Obtain the v1.2.0 language archive from the preceding release. The repair helper verifies its input hash and preserves every non-script entry:

```sh
python3 scripts/patch_tools/repair_candidate.py /path/to/v1.2.0/patch_lang_english.xp3 /tmp/v1.2.1/patch_lang_english.xp3
python3 scripts/test-patch-display.py
```

The second command verifies the archive shipped in this checkout against its manifest, the display safeguards, and the bound native evidence report. It does not start the native game.
